Les choix techniques

Chaque choix est justifié dans le cahier technique

BesoinChoixPourquoi
ApplicationFlutter (Dart)Une seule base de code pour 4 plateformes, déjà utilisée sur SYNCRO
Serveur (API)Node.js et ExpressMaîtrisé, minimaliste, le plus documenté
Base de donnéesMySQL dans DockerDonnées très liées : les clés étrangères gardent la cohérence
DocumentsScaleway Object StoragePayé à l'usage : le volume est impossible à prévoir
E-mailsScaleway Transactional EmailEnvoyés depuis le domaine de l'application
NotificationsFirebase + notifications localesPush sur téléphone, alertes sur ordinateur
HébergementScaleway, région ParisDonnées en France, un seul fournisseur
